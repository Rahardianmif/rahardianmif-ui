# Card

Card Core adalah container visual non-interaktif untuk mengelompokkan content yang memiliki hubungan kontekstual.

Card tidak boleh menjadi wrapper default untuk setiap elemen halaman.

## Purpose

Gunakan Card ketika sekelompok content memang perlu dipresentasikan sebagai satu unit yang jelas.

Contoh:

```text
Account summary
Payment information
System health summary
Configuration group
Profile summary
