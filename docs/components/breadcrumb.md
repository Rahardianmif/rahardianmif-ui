# Breadcrumb

Breadcrumb menyediakan hierarchical navigation yang membantu user memahami posisi halaman saat ini di dalam struktur website atau application.

Breadcrumb v0.4.1 bersifat CSS-only.

## Public API

```text
.rm-breadcrumb
.rm-breadcrumb__list
.rm-breadcrumb__item
.rm-breadcrumb__link
.rm-breadcrumb__separator
.rm-breadcrumb__current
