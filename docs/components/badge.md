# Badge

Badge adalah label kecil non-interaktif untuk category, metadata, role, atau state singkat.

Badge tidak menggantikan Button, Chip, Tag, atau Status Indicator.

## Purpose

Gunakan Badge ketika sebuah label singkat perlu membantu user memahami category, metadata, role, atau state ringkas.

Contoh:

```text
Draft
Administrator
Paid
New
Finance
