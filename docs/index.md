# Rahardianmif UI

Rahardianmif UI adalah reusable frontend UI system yang dibangun dengan:

- HTML
- native CSS
- Vanilla JavaScript

Core Rahardianmif UI tetap framework-agnostic dan tidak membutuhkan runtime framework.
