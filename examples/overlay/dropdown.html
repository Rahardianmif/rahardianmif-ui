Application action menus with native Popover, keyboard navigation, roving focus, alignment, typeahead and shared floating ownership.

Dropdown Menu — Light Theme

Basic Actions

Open the menu using click, Enter, Space or ArrowDown. ArrowUp opens the menu and focuses the final enabled item.

Alignment

Dropdown supports logical start, center and end alignment. Placement and alignment remain collision-aware.

Keyboard Navigation & Typeahead

Use Arrow Up, Arrow Down, Home, End, Enter, Space and Escape. Typing letters searches enabled menu items.

Item States

Disabled items are skipped by keyboard navigation and typeahead. Danger remains a semantic visual treatment only.

Navigation Items

Links are valid menu items when the Dropdown represents a compact application action menu.
