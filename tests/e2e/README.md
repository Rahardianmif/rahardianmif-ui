# End-to-End Tests

Rahardianmif UI v0.1 hanya mencakup Foundations + Tokens.

Belum terdapat application workflow atau complex component flow yang membutuhkan end-to-end test.

Folder ini dipertahankan karena `e2e` merupakan bagian dari testing domain resmi Rahardianmif UI.

End-to-end tests akan ditambahkan ketika roadmap memasuki component atau pattern yang memiliki workflow lintas component.

Jangan membuat artificial E2E test hanya untuk mengisi folder.
